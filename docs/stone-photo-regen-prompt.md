# Завдання: згенерувати фото натурального каменю

Потрібно створити 60 фотореалістичних зображень натурального каменю для сайту
каменеобробної майстерні. Робота у два етапи: спершу етап 1 (2 файли) повністю,
перевірити, що файли не порожні і на них саме поверхня каменю, лише потім
етап 2 (58 файлів). Генерувати лише перелічені нижче файли з точно такими
іменами. Нічого не додавати від себе: ні інших каменів, ні додаткових ракурсів.

## 1. Правила для всіх зображень

- Фотореалістична зйомка натурального каменю. Без тексту, етикеток, табличок із назвою, водяних знаків, рамок, логотипів, людей.
- Роздільна здатність від 2048×2048 для квадрата або 2400×1600 для формату 3:2. Менша не підходить.
- Для типів «свотч» і «картка» камінь заповнює весь кадр: знімок полірованої поверхні впритул, а не плитка чи зразок на столі. Жодних ребер плитки, країв, фону, тіней, відблисків-плям.
- Один камінь = одна текстура на всіх його файлах, різний лише масштаб і сюжет.
- Граніт, габро, кварцит: полірована поверхня, м'яке рівне розсіяне світло, легкий рівномірний блиск без «мокрого» ефекту.
- Онікс: напівпрозорий шаруватий камінь; на «застосуванні» показувати з підсвіткою ззаду, щоб камінь світився.
- Травертин: видно дрібні природні пори.
- Вапняк: матова, не дзеркальна поверхня.

## 2. Типи файлів

| Тип | Ім'я файлу | Формат | Що на зображенні |
|---|---|---|---|
| Свотч | `stone/<slug>.jpg` | квадрат | полірована поверхня впритул на весь кадр, без перспективи |
| Картка | `materials/<slug>.webp` | 3:2 | полірована поверхня на весь кадр, ледь помітна перспектива, рисунок у центрі |
| Сляб | `collections/<slug>-slab.webp` | 3:2 | ціла полірована плита каменю на металевій стійці у складі або шоурумі, нейтральний світло-сірий фон, видно повний рисунок каменю |
| Застосування | `collections/<slug>-application.webp` | 3:2 | камінь у готовому виробі в реальному інтер'єрі чи екстер'єрі: сюжет вказано для кожної групи нижче |
